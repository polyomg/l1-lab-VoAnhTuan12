How to use:
1. Edit src/main/resources/application.properties to set your Gmail username and app password.
2. Build: mvn clean package
3. Run: mvn spring-boot:run
4. Access:
   - http://localhost:8080/mail/form  -> mail form
   - http://localhost:8080/auth/login -> login page

Notes:
- This is a minimal example for the lab requirements (MailService, scheduling, AuthInterceptor, LogInterceptor).
- H2 in-memory DB is used; you can pre-load accounts by using AccountService in a CommandLineRunner if needed.
